
# Publication Checklist
## Healthcare AI Governance & Assurance

**Repository:** healthcare-ai-governance-assurance

**Author:** Dr. Samuel Israel, MD

**Purpose:** Ensure that all published governance artifacts are accurate, professionally presented, and suitable for public portfolio use.

---

## 1. Repository Quality

- [ ] README.md accurately describes the project.
- [ ] All three Excel workbooks are uploaded.
- [ ] Filenames match the README links.
- [ ] Workbooks open without errors.
- [ ] Worksheets, tables, and formulas are intact.
- [ ] No temporary or duplicate files are included.

## 2. AI System Inventory

- [ ] ReadmitAI is identified as ANIHG-AI-001.
- [ ] SepsisIQ V2 is identified as ANIHG-AI-002.
- [ ] System names and lifecycle stages are accurate.
- [ ] Assurance and deployment statuses are current.
- [ ] Ownership and accountability fields are accurate.
- [ ] No institutional approvals are implied.

## 3. AI Risk Registers

- [ ] ReadmitAI risks match its documented model limitations.
- [ ] SepsisIQ V2 risks match its documented safety findings.
- [ ] Risk scores and classifications are preserved.
- [ ] Existing controls are distinguished from proposed controls.
- [ ] Residual risks are not presented as formally accepted.
- [ ] Risk owners and approval roles are correctly represented.
- [ ] Risk identifiers are consistent or discrepancies are documented.

## 4. Privacy and Confidentiality

- [ ] No patient-identifiable information is included.
- [ ] No confidential hospital or employer information is included.
- [ ] No passwords, API keys, or access credentials are included.
- [ ] No sensitive personal information is exposed.
- [ ] Hidden worksheets, comments, and workbook metadata are reviewed.
- [ ] All content is appropriate for public distribution.

## 5. Governance Accuracy

- [ ] Research and prototype status is clearly stated.
- [ ] Clinical deployment restrictions are documented.
- [ ] No clinical effectiveness claims are made without evidence.
- [ ] No regulatory certification is implied.
- [ ] References to NIST AI RMF and ISO/IEC 42001 are accurate.
- [ ] Independent portfolio work is distinguished from institutional governance approval.

## 6. Final Publication Review

- [ ] All workbook versions are final for publication.
- [ ] README descriptions match the actual deliverables.
- [ ] Repository links work.
- [ ] GitHub repository visibility is appropriate.
- [ ] LinkedIn project description matches the published evidence.
